# Maibot Knowledge Loop

麦麦（MaiBot）「求知闭环」设计方案。

让麦麦从"被动应答"变成"主动求知"：遇到不认识的高价值词，
能主动发现认知缺口 → 自行查询形成候选 → 向群友求证 → 把学到的词义
以"多义并存"的方式永久记住，且不破坏麦麦原有的记忆结构。

## 方案要点

- **六段链路**：识别 → 采集观察 → 价值算法 → 单发求证 → 多义落库 → 节流回退
- **三层数据解耦**：terms / term_senses / entities（一词多义无上限，同义词同指一人/事）
- **多因子价值算法**：7 因子归一化加权 + 熵权法定权，各下级公式有论文依据
- **语义漂移检测**：词义随时间变化时，未知度动态回升、重新求知
- **核心承诺**：新存储完全独立，不改动 `a-memorix` 记忆库与 `jargons` 黑话库，可整体卸载
